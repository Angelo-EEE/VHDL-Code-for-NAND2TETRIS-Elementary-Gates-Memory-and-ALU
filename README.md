# NAND2TETRIS-Elementary-Gates-Memory-and-ALU

The NAND2TETRIS course teaches how to make a simple, working CPU that can access peripherals such as a keyboard and monitor to perform general basic CPU tasks and even play games like Pong and Tetris. This is all made from only NAND gates. 

I decided to use the NAND2TETRIS course to aid in teaching me the basics of the VHDL hardware description language and digital logic design and so the code can definitely be improved upon and is not up to industry standard, especially the testbenches as they are not self checking. This was a learning experience for me and although I found it challenging, it was quite rewarding to be able to come up with solutions for how to make each component form only NAND gates. When putting everything together to make the ALU, it felt very satisfying to get an end product that worked and to look back on how I started from making a simple AND gate.
